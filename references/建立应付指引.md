# 建立应付指引（多维表 → GoFreight，给 AI 和业务看）

> 目标：把多维表里**新入库的发票行**逐笔录进 GoFreight「建立应付」，替代手工录入。
> 铁律：**先出清单、用户确认、再提交**——AI 永远不能自行加 `--yes`。

## 一、口径（固定，不商量）

每条多维表行（= 一个 TK 一笔）对应一张 GoFreight 应付单：

| GoFreight 字段 | 取值 |
|---|---|
| TK / MBL | 表内「TK号」 |
| 供应商 | 表内「服务商名称」经 `GOFREIGHT_VENDOR_MAP` 映射成编号 |
| 发布日期 / 发票日期 | 表内「开票日期」（两个都填开票日期） |
| 到期日 | 表内「发票DUE date」 |
| 费用代码 | `.env` 的 `GOFREIGHT_FEE_CODE`（管理员发的口径值，逐字照抄） |
| 数量 × 单价 | **1 × 该行「摊分金额」**（金额自动相乘，不用手填） |
| 币种 | 表内「发票币种」（缺省按 CAD） |

## 二、流程（每轮三步）

1. **出清单**：`python_venv\Scripts\python -m gofreight_ap --env-file .env plan`
   ——只读多维表，打印待录清单（发票号 | TK | 供应商→编号 | 金额币种 | 开票/到期日）
   和跳过清单（含原因）。**把清单原样念给用户看，等确认。**
2. **确认后提交**：用户回复确认（「可以」「提交」）后才执行
   `... -m gofreight_ap --env-file .env submit --yes`
   ——逐行提交：每行先查该 TK 会计页有没有同发票号（别人手工录过→自动跳过防双录并记账），
   然后填表单提交。某行失败自动截图 `runtime-outputs\gofreight\FAIL_*.png` 并**继续下一行**。
3. **收尾汇报**：成功 X/N；失败的念出发票号|TK 和步骤名，截图路径告诉用户，转人工补录
   （人工在 GoFreight 录完后可用 `mark --invoice N --tk TK-x` 补记防重，避免下轮重复录）。

范围缩水：`plan --invoice 1001`（只看某发票）、`--tk TK-xxx`（只看某 TK）、
`--limit 5`（本轮最多 5 行）——适合分批或单笔重试。

## 三、哪些行不会被录（跳过=保护，不是故障）

| plan 里的原因 | 含义 | 怎么办 |
|---|---|---|
| 已建立应付（state 记账） | 本机防重账本记过 | 不用管 |
| 会计页已有该发票号（提交时跳过） | 别人已手工录过 | 不用管（自动记账） |
| 服务商无映射 | 管理员还没配这家的 GoFreight 编号 | **找管理员**要 `search`/`code` 配进 `.env` 的 `GOFREIGHT_VENDOR_MAP`，绝不猜编号 |
| 表内异常未清 | 该行「异常报错」列有字 | 先在多维表人工补全、清掉异常标注 |
| 缺发票号/TK、摊分金额缺失或为 0、开票日期缺失、DUE 缺失 | 行数据不完整 | 在多维表补齐 |

## 四、防重（三层，都不要绕）

1. **本机账本** `data\gofreight_state.json`：按「发票号|TK」记账，提交成功即落盘——**别删这文件**。
2. **提交预检**：每行提交前查该 TK 会计页，已有同发票号就跳过（新机器账本为空时靠这层兜底）。
3. **人工补记** `mark`：管理员说某笔别人已录过，用 `mark --invoice N --tk TK-x` 补进账本。

## 五、配置（管理员另发，写进 `.env`，同样属于钥匙不能转发）

| 键 | 说明 |
|---|---|
| `GOFREIGHT_BASE_URL` | 系统地址（管理员发，`https://` 开头） |
| `GOFREIGHT_USER` / `GOFREIGHT_PASSWORD` | 录应付用的账号（谁的账号谁机器上跑） |
| `GOFREIGHT_FEE_CODE` | 费用代码口径值（逐字照抄管理员发的） |
| `GOFREIGHT_VENDOR_MAP` | 供应商映射 JSON：`{"表内服务商名": {"search": "无空格短词", "code": "编号"}}`；search 不能带空格（系统下拉限制） |
| `GOFREIGHT_STATE_PATH` / `GOFREIGHT_SHOT_DIR` | 一般不用改（账本/截图默认位置） |

## 六、环境与账号注意

- 需要本机装有 **Chrome 或 Edge**（工具自动调用系统浏览器）；缺 playwright 组件时先
  `python_venv\Scripts\pip install -r requirements-gofreight.txt`。
- GoFreight **单会话互踢**：提交期间这个账号不能在别的电脑/浏览器登录，开始前先退掉。
  提交中提示「会话过期，重新登录」是正常的（约 15 分钟过期，自动重登）。
- 凭证错/被互踢会停在 `FAIL_login` 并截图——核对 `.env`、关掉别处登录，只重跑失败的那几行。
