========================================================================
   结算邮件自动录入工具 · 快速上手（先看这一页就够）
   版本 1.5.3
========================================================================

【这个工具是干什么的】
   监听你的 Lark 邮箱，把「结算确认（confirm）」邮件自动录入多维表：
   解析每封邮件里的 TK 号和数量，按数量把发票金额摊分到每个 TK，
   发票 PDF 自动挂附件，并从 PDF 识别服务商/币种/开票日期等。
   解析不了的邮件不会丢——会带着「异常报错」说明落进表里，等你人工补。
   （可选）还能把表里的新发票逐笔录进 GoFreight「建立应付」——
   工具先出清单，你确认一句才真提交，录过的自动跳过。


【你需要准备（缺一不可）】
   1. Windows 电脑，装好 Python 3.9 或更高版本
      没有就去 https://www.python.org/downloads/ 下载，
      安装时务必勾选 "Add python.exe to PATH"
   2. 一个能读写本地文件、执行命令的 AI 助手（WorkBuddy 这类）
   3. 管理员发给你的 GitHub 项目链接 + 结算表链接
      （AI 能从链接里自己认出表信息，不用你手抄两串码）
   4.（只用建立应付时）管理员另发的 GoFreight 配置五样
      （地址/账号/密码/费用代码/供应商映射），以及电脑上装有 Chrome 或 Edge


【六步开始】

   第 1 步   申请你自己的企业自建应用（一次性，约 15-30 分钟）
   ---------------------------------------------------------------
   工具用你自己名下的应用凭证读邮箱、写表（App ID 是 cli_ 开头那串）。
   按 references\应用申请指引.md 走：建应用（记得加"机器人"能力）→
   开 6 个权限 → 发布（管理员审批）→ 可用范围加自己 →
   管理员把应用加为多维表文档应用。
   手生就直接对 AI 说："按 应用申请指引.md 带我申请应用"。

   第 2 步   下载本项目，装进你的 AI
   ---------------------------------------------------------------
   项目是 GitHub 上的公开开源仓库（地址向管理员要），下载不需要
   GitHub 账号。目标位置固定为：
   C:\Users\<你的用户名>\.workbuddy\skills\lark-mail-sync
   （这个文件夹不存在就新建一个；手生就跳过，直接让 AI 代办——
    在对话里说："请按 README 把 lark-mail-sync 从 GitHub 装到
    .workbuddy\skills 下"，AI 知道该怎么做。）

   · 电脑有 git（推荐）：
       git clone <管理员发的链接> "%USERPROFILE%\.workbuddy\skills\lark-mail-sync"

   · 没有 git：
       浏览器打开链接 → 绿色 Code 按钮 → Download ZIP →
       解压出 lark-mail-sync-<分支名> 文件夹 → 改名为 lark-mail-sync →
       整个挪进 C:\Users\<你的用户名>\.workbuddy\skills\ 下

   第 3 步   双击 setup.bat
   ---------------------------------------------------------------
   自动创建运行环境并跑离线自测，首次约 1-3 分钟。
   看到 "Setup finished successfully" 就是成功了。

   第 4 步   双击 config-env.bat，填写配置（或者直接发给 AI 代填）
   ---------------------------------------------------------------
   方式 A（推荐，不用手填）：把 4 样信息发给 AI——
       App ID / App Secret（第 1 步抄的）、你的邮箱、结算表链接
       （整条链接原样贴，AI 自己从里面认出表，两串码不用手抄）——
       再说一句 "请用【邮件同步 SKILL】帮我填好配置，再检查一遍
       是不是都能正常用"。
   方式 B：双击 config-env.bat 弹出记事本，把下面几项填进等号后面：
       LARK_APP_ID / LARK_APP_SECRET      第 1 步你自己申请的应用凭证
       MAIL_USER_MAILBOX_ID               你自己的邮箱地址
       BITABLE_APP_TOKEN / BITABLE_TABLE_ID  目标表（管理员给，照抄）
       BITABLE_APP_ID / BITABLE_APP_SECRET  留空（同一应用既读邮件又写表）
       GOFREIGHT_ 开头五项（可选）        管理员发的 GoFreight 配置，
                                          不用建立应付就整段留空
   ⚠ 填好的 .env 等于钥匙，不要截图、不要发人、不要提交到任何地方。

   第 5 步   首次使用，在对话里说：
   ---------------------------------------------------------------
   请用【邮件同步 SKILL】做一次环境自检，然后恢复同步状态，
   再跑一轮同步。

   AI 会依次执行：probe（自检四项全通）→ rebuild-state（恢复去重游标，
   新电脑必做，跳过会造成重复录入！）→ sync（第一轮同步）。

   第 6 步   以后每次用，只需说：
   ---------------------------------------------------------------
   请用【邮件同步 SKILL】跑一轮同步。

   想顺手把处理完的邮件移出收件箱（归档），再说一句：
   请用【邮件同步 SKILL】归档已处理邮件。
   （只动已录进表的结算邮件，其他邮件一封不碰；移错了去邮箱
    "Archived" 文件夹手动移回即可。）

   要把新发票一路录进 GoFreight（建立应付），说：
   请用【邮件同步 SKILL】出一份建立应付清单。
   这一句就是完整流程：AI 会先同步最新结算邮件进表，
   再念出本轮要录的清单；你确认一句（"可以提交"），它才逐笔录入；
   录过的自动跳过，个别失败的会自动截图留给人工补。
   注意：提交期间你的 GoFreight 账号别在别的电脑/浏览器登录（会互踢）。

   不想说话也可以直接双击 sync.bat（效果相同，仅同步功能）。


【三条纪律（请务必遵守）】
   1. 绝不让 AI 执行 backfill（全量回填）或 reset-table（清空表格）
      ——见下"红线"。
   2. data\state.json 是本机的去重游标，data\gofreight_state.json 是
      建立应付的防重账本，两个都别删；state.json 误删后对 AI 说
      "恢复同步状态"（rebuild-state）即可补救。
   3. 多维表是共享的：发现录错的行，在表里人工处理或找管理员，
      不要让 AI 成批删改表内已有数据。
   4. 建立应付永远是"先清单、后确认"：AI 没听到你说"可以提交"
      就不该真提交——它若直接提交了，停下来报告管理员。


【更新版本】
   管理员说"有新版"时：
   · git 装的：在文件夹里执行  git pull  然后重跑 setup.bat 即可
     （.env 和 data\ 不会被更新覆盖，放心）。
   · ZIP 装的：删掉旧文件夹按第 2 步重下（.env 先复制出来，
     装好后贴回去），然后重跑 setup.bat。


【换电脑 / 重装后怎么办】
   新机器：按第 2 步装项目 → setup.bat → config-env.bat 填配置 →
   对 AI 说 "恢复同步状态，然后跑一轮同步"。
   （应用不用重新申请，.env 里的凭证继续用。）


【出问题了看哪里】
   · 连不上 / 权限报错 / 重复录入 / 中文乱码……
     让 AI 按 SKILL.md 第七节"故障手册"处理（AI 知道这本书在哪）。
   · 应用申请相关（99991672 / 建不了应用 / Secret 看不到）：
     references\应用申请指引.md 末尾的"常见卡点速查"。
   · 更详细的口径说明（每列怎么填、金额怎么摊、异常报错含义）：
     references\录入口径.md


【项目内文件一览】
   SKILL.md                给 AI 读的操作说明书（红线+命令+故障手册）
   LICENSE                 开源协议（MIT）
   references\应用申请指引.md  自己申请企业自建应用的分步指引
   references\录入口径.md   数据口径与防重规则（每列怎么填）
   references\建立应付指引.md  建立应付口径、确认流程与防重
   lark_mail_sync\         Python 源码（邮件→多维表）
   gofreight_ap\           Python 源码（多维表→GoFreight 建立应付）
   tests\ tests_internal\  离线自测（无需网络）
   .env.example            配置模板（凭证留空，填你自己申请的）
   setup.bat               一键装环境 + 自测（第一次用）
   config-env.bat          生成并编辑 .env（填配置）
   sync.bat                双击跑一轮同步（手动入口）
   使用指引.txt            本文件
   README.md               速览
